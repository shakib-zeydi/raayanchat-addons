## ✨ درباره این مخزن

این مخزن محل قرارگیری **Add-on**های رایان‌چت است؛ از پلاگین‌های آماده برای سیستم‌های مدیریت محتوا تا SDKها، پکیج‌ها و اتصال‌دهنده‌های مخصوص زبان‌ها و فریم‌ورک‌های مختلف.

هدف این مخزن، ساده‌کردن استفاده از رایان‌چت در پروژه‌های گوناگون و فراهم‌کردن بستری برای توسعه جامعه‌محور است.

## 🧱 چه چیزهایی در این مخزن قرار می‌گیرد؟

### 🔌 پلاگین‌ها و اتصال‌دهنده‌ها

- پلاگین WordPress
- اتصال به WooCommerce
- ماژول‌ها و افزونه‌های CMSهای مختلف
- اتصال به فرم‌ها، فروشگاه‌ها و سیستم‌های پشتیبانی

### 📦 پکیج‌ها و SDKها

- پکیج Python
- پکیج Django
- پکیج Laravel و PHP
- پکیج React
- پکیج JavaScript و TypeScript
- SDK برای زبان‌ها و فریم‌ورک‌های آینده

### 🛠️ ابزارهای توسعه

- کامپوننت‌های آماده
- Middleware و Helperها
- ابزارهای احراز هویت و اتصال API
- نمونه‌کدها و قالب‌های شروع سریع
- ابزارهای تست و توسعه

> این فهرست محدود نیست و با نیاز کاربران و مشارکت توسعه‌دهندگان گسترش پیدا می‌کند.

## 🗂️ ساختار پیشنهادی

هر Add-on می‌تواند به‌صورت یک پکیج مستقل در این مخزن قرار بگیرد:

```text
addons/
├── wordpress/
│   └── rayan-chat/
├── python/
│   └── rayan-chat-sdk/
├── django/
│   └── rayan-chat/
├── laravel/
│   └── rayan-chat/
├── react/
│   └── rayan-chat/
└── javascript/
    └── rayan-chat-sdk/
```

ساختار نهایی ممکن است بر اساس تعداد پروژه‌ها و روش انتشار هر Add-on تغییر کند. هر Add-on باید README، مستندات نصب و نمونه استفاده مستقل داشته باشد.

## 🎯 اهداف پروژه

- ارائه ابزارهای رسمی و جامعه‌محور

- فراهم‌کردن API و تجربه توسعه یکپارچه

## 📦 نصب و استفاده

روش نصب به نوع Add-on بستگی دارد. برای نمونه:

### پکیج‌های JavaScript

```bash
npm install <package-name>
```

### پکیج‌های Python

```bash
pip install <package-name>
```

### پکیج‌های Laravel

```bash
composer require <vendor/package>
```

### پلاگین WordPress

1. فایل ZIP افزونه را دریافت کنید.
2. از بخش **Plugins > Add New > Upload Plugin** آن را نصب کنید.
3. افزونه را فعال کنید.
4. تنظیمات اتصال به رایان‌چت را تکمیل کنید.

> دستورهای واقعی پس از انتشار هر Add-on در README همان پروژه ثبت می‌شوند.

## 🔐 اصول امنیتی

- کلیدهای API و اطلاعات محرمانه را در کد یا Git قرار ندهید.
- اطلاعات حساس را از طریق متغیرهای محیطی یا تنظیمات امن ذخیره کنید.
- ورودی‌های کاربر را در سمت Add-on و بک‌اند اعتبارسنجی کنید.
- از ثبت توکن‌ها و اطلاعات خصوصی در Logها جلوگیری کنید.
- دسترسی‌ها را بر اساس حداقل سطح مجاز تعریف کنید.
- سازگاری نسخه‌ها و تغییرات API را مستند کنید.
- قبل از انتشار، وابستگی‌ها را از نظر آسیب‌پذیری بررسی کنید.

## 🤝 مشارکت

از توسعه Add-onهای جدید و بهبود پروژه‌های موجود استقبال می‌کنیم.

برای مشارکت:

1. مخزن را Fork کنید.
2. یک شاخه برای تغییرات خود بسازید.
3. Add-on جدید یا تغییرات خود را همراه با مستندات اضافه کنید.
4. تست‌های لازم را بنویسید.
5. یک Pull Request ایجاد کنید.

هر Add-on جدید باید تا حد امکان موارد زیر را داشته باشد:

- README مستقل
- روش نصب و استفاده
- نسخه‌ها و پیش‌نیازها
- نمونه کد
- تست‌های پایه
- توضیح مجوز و وابستگی‌ها

برای گزارش خطا یا پیشنهاد قابلیت جدید، یک Issue ایجاد کنید.

## 🧭 پیشنهاد نام‌گذاری

برای هماهنگی بیشتر، نام پکیج‌ها بهتر است از الگوی زیر پیروی کند:

```text
rayan-chat-<platform>
```

یا برای پکیج‌های عمومی:

```text
rayan-chat-sdk-<language>
```

نام نهایی باید پیش از انتشار با ساختار رجیستری مربوط به همان زبان یا پلتفرم بررسی شود.

## 📚 مستندات

مستندات هر Add-on باید در پوشه یا مخزن مربوط به همان Add-on قرار داشته باشد. مستندات عمومی رایان‌چت و قراردادهای API نیز می‌توانند در این مخزن نگهداری شوند.

## 📄 مجوز

مجوز این مخزن و Add-onهای آن باید در فایل `LICENSE` و همچنین در مستندات هر Add-on مشخص شود. ممکن است Add-onهای مختلف با توجه به وابستگی‌ها یا تصمیم نگهدارندگان، شرایط مجوز متفاوتی داشته باشند.
